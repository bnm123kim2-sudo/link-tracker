# 내 링크 트래커 (CPA 링크 클릭 추적기)

블로그에 올릴 CPA(마이리얼트립 등) 링크를 등록하고, 클릭수를 추적하는 아주 작은 도구예요.

## ⚠️ 먼저 알아둘 것

- 이 도구는 **클릭 수**만 기록해요. 실제 **구매/전환/수익**은 이 도구로 알 수 없어요.
  (결제는 마이리얼트립 서버에서 일어나므로, 실제 수익은 반드시 마이리얼트립 파트너스 페이지에서 확인하세요.)
- 여기에 넣는 링크는 **이미 마이리얼트립 파트너스(partner.myrealtrip.com)에서 직접 만든 정식 CPA 링크**를 붙여넣어야 해요.
  출처가 불분명한 제3자 사이트가 대신 만들어주는 링크는 수수료가 다른 사람에게 갈 위험이 있으니 쓰지 마세요.
- 지금 버전은 데이터를 `data.json`이라는 파일 하나에 저장해요. 개인이 혼자 쓰기엔 충분하지만,
  방문자가 아주 많아지면 나중에 진짜 데이터베이스(SQLite/PostgreSQL)로 바꾸는 걸 추천해요.

## 1. 로컬에서 실행하기

Node.js가 설치되어 있어야 해요 (https://nodejs.org 에서 LTS 버전 설치).

```bash
cd link-tracker
npm install
node server.js
```

실행되면 터미널에 아래처럼 뜨고,

```
서버 실행 중: http://localhost:3000
```

브라우저에서 `http://localhost:3000` 을 열면 관리 화면이 보여요.

## 2. 사용 방법

1. 관리 화면에서 마이리얼트립 파트너스에서 만든 CPA 링크와, 어떤 글에 쓸 건지 라벨(글 제목)을 입력하고 "만들기" 클릭
2. 생성된 단축 링크(`http://내주소/r/코드`)를 복사해서 블로그 글에 삽입
3. 나중에 관리 화면에서 새로고침하면 각 링크별 클릭수가 올라간 걸 확인 가능

## 3. 인터넷에 배포해서 실제로 쓰기

로컬(`localhost`)은 본인 컴퓨터에서만 보여서, 블로그 독자가 클릭해도 작동하지 않아요.
실제로 쓰려면 24시간 켜져 있는 서버에 올려야 해요. 무료로 시작할 수 있는 곳들:

- **Render** (render.com) — Node.js 앱을 깃허브 연결만 하면 자동 배포
- **Railway** (railway.app) — 비슷하게 간편함
- **Fly.io** — 무료 티어 있음, 약간 더 기술적

공통 절차:
1. 이 폴더를 GitHub 저장소에 올리기
2. 위 서비스 중 하나에서 "GitHub 저장소 연결 → 배포" 클릭
3. 배포되면 `https://내프로젝트이름.onrender.com` 같은 주소가 생김
4. 그 주소로 블로그 링크를 만들면 실제로 작동함

⚠️ 주의: 무료 플랜은 대부분 `data.json` 파일이 재배포/재시작 시 초기화될 수 있어요.
데이터를 계속 유지하고 싶으면 나중에 SQLite나 외부 DB(예: Supabase, Railway의 Postgres 애드온)로 옮기는 걸 권장해요. 필요하면 그 마이그레이션도 도와드릴 수 있어요.

## 4. 폴더 구조

```
link-tracker/
├── server.js       # 서버 로직 (링크 생성, 리다이렉트+클릭기록, API)
├── db.js           # 데이터 저장/불러오기 (JSON 파일 기반)
├── package.json
└── public/
    └── index.html  # 관리 화면 (링크 생성 + 목록/클릭수)
```
